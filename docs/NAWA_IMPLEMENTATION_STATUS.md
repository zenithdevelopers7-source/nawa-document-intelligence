At [`83c0e74`](https://github.com/zenithdevelopers7-source/nawa-document-intelligence/commit/83c0e74d88b70b6a9b4a4dcd29c1d052b1d952d1), [synthetic PostgreSQL and browser checks](https://github.com/zenithdevelopers7-source/nawa-document-intelligence/actions/runs/44742801615) passed. This is a test draft, not a merged release; reconcile changes if #9 or #10 is applied upstream so they are not duplicated.

The follow-up at [`d4ebd51`](https://github.com/zenithdevelopers7-source/nawa-document-intelligence/commit/d4ebd51e8dc733d77f6d69e3eb1e4b8f6866616d) adds a [synthetic retrieval experiment](https://github.com/zenithdevelopers7-source/nawa-document-intelligence/blob/d4ebd51e8dc733d77f6d69e3eb1e4b8f6866616d/docs/synthetic-live-retrieval.md). Its [disposable PostgreSQL test](https://github.com/zenithdevelopers7-source/nawa-document-intelligence/actions/runs/44876104688) demonstrates that an old backup can reinstate a later-revoked grant. On a separate restored test database, a manual deny-all reset blocked both test tenants until one grant was explicitly restored; this is not an automated recovery procedure or a command for an existing database. The [earlier browser run](https://github.com/zenithdevelopers7-source/nawa-document-intelligence/actions/runs/44874843550) exercised default denial, a fixture-managed grant, same-tenant and cross-tenant denial, CSRF and grant revocation using synthetic Keycloak sessions. Inputs use bounded POST bodies; infrastructure could still log them. The endpoint and controls affect only this experimental path, not the running portal or other services. There is no grant-administration endpoint; the reviewer delegation policy is an unapproved test assumption. New synthetic migrations are included for review; existing databases have not been migrated. Recovery does not reconstruct decisions after the backup; database and file reads are not atomic, and other races remain. This does not establish production isolation.

At [`12e44c0`](https://github.com/zenithdevelopers7-source/nawa-document-intelligence/commit/12e44c0ef74556fe0e4b985df365f2702a093ac8), a [nine-case synthetic retrieval fixture](https://github.com/zenithdevelopers7-source/nawa-document-intelligence/blob/12e44c0ef74556fe0e4b985df365f2702a093ac8/docs/synthetic-retrieval-evaluation.md) found the labeled source in the top five for all four answerable cases, and no search results for three of five cases labeled no-result. The English and Arabic missing-payment-date queries returned related VAT passages that did not contain the requested date. The offline extractive and mock-generation experiments use a strict lexical default and a small list of absence phrases; tested English and Arabic "not specified" examples abstained, while two present-date controls answered. A different synthetic sentence saying a deadline remains "unknown" was still labeled answered. The [test run](https://github.com/zenithdevelopers7-source/nawa-document-intelligence/actions/runs/44878737481) exercises these cases. Phrase matching is not semantic verification, and lowering the configurable threshold can admit unsupported answers. These hand-authored cases are not independently reviewed, this does not change the running portal, and these figures are not real-world quality, semantic abstention or isolation claims.

The subsequent [`bad4aac`](https://github.com/zenithdevelopers7-source/nawa-document-intelligence/commit/bad4aacf8facd666066b9348b4b9b8c89e580c8b) adds a [12-case synthetic answer-level fixture](https://github.com/zenithdevelopers7-source/nawa-document-intelligence/blob/bad4aacf8facd666066b9348b4b9b8c89e580c8b/docs/synthetic-answer-evaluation.md). One local run recorded six false answers among eight abstention-labeled cases and two false abstentions among four answerable cases. The [evaluation accounting tests](https://github.com/zenithdevelopers7-source/nawa-document-intelligence/actions/runs/44880402817) passed; that does not mean answer quality passed. Labels are hand-authored and not independently reviewed, and the fixture tests the offline extractive function, not the running portal or a real model. An instruction-like text was returned as an answer in one case; this does not establish that it was executed. Do not use the scores as production accuracy claims.
